OBJECTIVE: Extract insights using visual and statistical exploration.

TOOLS: Python(Pandas, Matplotlib, Seaborn)

DATASET: Titanic(train.csv)

SUMMARY:
-Most passengers in 3rd class and male had lower survival rates.
- Younger passengers and females had higher survival chances.
- There is a positive correlation between fare and survival.
- Embarkation from Cherbourg (C) was associated with higher survival rates.
- Pairplot and scatterplots indicate survival is influenced by multiple variables, especially fare, age, and class.
- Boxplots show non-survivors had a wider age spread than survivors.
